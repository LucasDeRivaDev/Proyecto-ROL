# Changelog

## v0.1

Primera release manual de `RolMaster Kit: La Forja del Dungeon Master`.

### Incluye

- generador de NPCs con retrato procedural
- generador de mazmorras con minimapa procedural
- generador de misiones con escena procedural
- encuentros rapidos, rumores, tabernas, asentamientos, facciones y tesoros menores
- historial, favoritos persistentes y fijado de resultados
- exportacion TXT individual y de campana completa
- exportacion SVG de visuales
- galeria visual de campana
- ficha de sesion en HTML
- modo impresion
- importacion y exportacion de campanas en JSON
- nombre de campana editable con portada visual procedural

### Correcciones relevantes

- compatibilidad reforzada con Live Server
- correcciones de parseo en exportacion HTML
- saneamiento de nombre de campana en exportaciones
- saneamiento adicional en UI e importacion JSON

### Estado esperado

Version apta para testing manual completo y validacion de experiencia de uso.
